# Présentation du projet


## Objectifs
- Mieux valoriser les données de prélèvements d’eau
- Rapprocher les données Agence / DDT(M)
- Produire des indicateurs et cartographies directement exploitables

## À qui s’adresse VOCAL ?
- Agents DDT(M)
- Agents Agence de l’eau
- EPTB
- Chargés de mission eau / SIG

## Philosophie
VOCAL est un **outil d’aide à l’analyse**, basé sur la qualité des données en entrée.
