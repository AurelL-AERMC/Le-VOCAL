# Exercices


Les exercices suivants sont conçus pour une formation ou une prise en main autonome.

## Exercice 1 — Découverte du plugin
Objectif : ouvrir le plugin et charger une zone d’étude.

<details>
<summary>Indice</summary>

Le plugin est accessible via le menu Extensions de QGIS.
</details>

<details>
<summary>Solution</summary>

Ouvrir QGIS → Extensions → VOCAL → choisir un programme → charger une zone.
</details>
