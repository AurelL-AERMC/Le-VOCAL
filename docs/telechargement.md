# Téléchargement du Plugin

Le plugin **VOCAL** est distribué sous la forme d’un dossier compressé (ZIP), à installer manuellement dans QGIS.

---

## Lien du téléchargement : 
Renvoi directement sur le contenu du GitHub : https://github.com/AurelL-AERMC/Le-VOCAL

Vous pouvez télécharger en cliquant ici : [ Télécharger le plugin VOCAL](https://github.com/AurelL-AERMC/Le-VOCAL/archive/refs/heads/main.zip)

## Installation dans QGIS 

1. Télécharger le fichier ZIP
2. Ouvrir QGIS
3. Menu **Extensions → Installer/Gérer les extensions**
4. Onglet **Installer depuis un ZIP**
5. Sélectionner le fichier téléchargé
6. Redémarrer QGIS si demandé
